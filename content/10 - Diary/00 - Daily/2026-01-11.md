## ShadCN Content Catalog - First Open Source Repo
Today I finalized my first open-source project called [[ShadCN Content Catalog]]. It integrates with AWS S3 to deliver MP3 and MP4 content to end-users via an intuitive youtube-like interface where users can enter search terms, filters, and sort-bys to find content they're interested in. Content options are displayed in a CSS grid where each item has its own thumbnail, title, series label, part number (if its a series), author name, and publish date. At this time, when a user clicks on an item, the item behaves just like a bare-bones `<a>` tag; It opens the specific URL endpoint for the content in a new tab and uses the browser's native playhead UI for interactions. A future improvement to this would be a dedicated playhead UI where MP3 and MP4 content can both be played in the same interface - A reasonably large media player which shows the video content if available, or just the thumbnail in a larger size if mp3 only.
