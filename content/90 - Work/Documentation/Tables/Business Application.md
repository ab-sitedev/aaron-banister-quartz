Business applications are records that describe software used by the organization in some way.

# Key fields to know

| Field               | Purpose                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Name                | Default display value for the record                                                                                           |
| Alias               | Alt name for apps referred to by something other than their name                                                               |
| Access type         | Standard apps appear in standardized access forms.<br>Unique apps appear in specific access forms that don't fit the standard. |
| Access structure    | Flat (Default) doesn't require group/role specification on access forms.<br>Group-based and Hybrid do.                         |
| Entities leveraging | List of entities who can select the app on access forms.                                                                       |
