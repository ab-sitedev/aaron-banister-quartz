Access profiles allow companies to standardize a list of [[Business Application|business applications]] necessary for specific job functions.

They're essentially templates that users can pick from when submitting an access form instead of having to pick each application one by one, reducing human error.

| Field                | Purpose                                   |
| -------------------- | ----------------------------------------- |
| Name                 | Provides a familiar name for the profile  |
| Company              | Relates the profile to a specific company |
| Default applications | List of apps associated with the profile  |
