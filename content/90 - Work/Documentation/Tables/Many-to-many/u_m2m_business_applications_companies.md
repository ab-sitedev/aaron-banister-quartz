Relationships between [[Business Application|business applications]], companies, groups, and provisioning engines

| Field                     | Purpose                                                                       |
| ------------------------- | ----------------------------------------------------------------------------- |
| Business application      | Defines the application related to this record                                |
| Company                   | Defines the company related to this provisioning obligation                   |
| Access provisioning group | Defines the group which should be obligated for provisioning this application |
| Provisioning engine       | Defines the provisioning engine (e.g., Okta, Azure, AD, etc...)               |
