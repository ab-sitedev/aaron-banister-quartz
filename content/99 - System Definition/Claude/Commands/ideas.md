Scan my vault for emerging patterns. Generate ideas for: tools I should build, people I should reach out to, topics I should investigate, and things I should write.

Follow these steps:

1. **Tag landscape:** Run `obsidian tags counts sort=count format=json` to see what topics dominate the vault by frequency. Note the top tags and any surprising ones.

2. **Recent activity:** Run `obsidian recents` to see what's been actively open. Cross-reference with the tag landscape — where do recents and high-frequency tags overlap?

3. **Search for friction and desire:** Run these targeted searches to surface signals:
   - `obsidian search:context query="I wish"`
   - `obsidian search:context query="frustrating"`
   - `obsidian search:context query="should build"`
   - `obsidian search:context query="want to write"`
   - `obsidian search:context query="reach out"`
   - `obsidian search:context query="look into"`

4. **Orphan notes:** Run `obsidian orphans` — isolated notes with no incoming links often represent ideas that haven't been connected to anything yet. Scan a sample of them.

5. **Daily notes (last 14 days):** Run `obsidian read` on each daily note from the past 14 days. Focus only on `## Notes` sections — skip task lists.

6. **Homepage:** Run `obsidian read path="00 - Pinned/Homepage.md"` for current priorities.

---

Synthesize into an **Idea Report**:

### Tools to Build
Based on recurring friction, manual workflows, or capabilities I keep wishing existed — 3–5 concrete tools or automations. Be specific: what it does and why it fits the patterns found.

### People to Reach Out To
Based on names or references that recur across notes, or topics where outside perspective would help — 3–5 people worth contacting. Explain the connection.

### Topics to Investigate
Based on threads that are underexplored or questions that keep surfacing — 3–5 topics worth deeper research. Include why each seems worth time right now.

### Things to Write
Based on ideas circled back to, opinions formed, or experiences worth capturing — 3–5 pieces worth writing. Include the angle or thesis for each.

---

Ground every suggestion in something concrete from the vault — a tag, a search hit, a note title, a phrase. No generic ideas.
